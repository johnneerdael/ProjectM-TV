# Source appearance and preference matching

This steering supersedes prioritizing complete47-field simulation replacement.
The user wants sufficiently accurate mood descriptions and editable preference
matching, with a machine-readable baseline visual description detailed enough
for an eventual approximate reconstruction. Exact positions and pixel equality
are not the objective of this layer. Continue in the same worktree with the
verified latest full2.3.33AAR (byte-identical32/31); no main merge or duplicate corpus
render is implied.

## Required output

- Identify contributing elements and their approximate forms, symmetry, layers,
  depth/feedback and possible transformations.
- Describe colour generation, including phase-shifted multi-channel palettes;
  distinguish generated colours from inherited unknown image/feedback contents.
- Link bass/mid/treble and their attenuated inputs to specific element controls:
  size, position, rotation, deformation, colour and opacity. Retain source
  transfer expressions, thresholds/clamps and available coefficients.
- Use stable IDs, documented numeric categories/units, source evidence and nulls
  for missing knowledge. Numbers must not masquerade as calibrated confidence.
- Derive mood/preference descriptions as a versioned interpretation of these
  facts. Fractal plus varied colour supports psychedelic potential; it does not
  imply permission to flash. Preserve the user's Chill/Normal/Party overlap and
  avoid confident Chill recommendations when flashing evidence is unresolved.
- Keep the existing47-field export intact; this richer descriptor is separate.

## Implementation sequence

1. Extend the existing source analysis rather than build another parser: expose
   a structured appearance record from its contributing RGB/geometry graphs.
2. Add palette-generation recognition and per-element audio-control routes with
   semantic negative/positive fixtures. Do not infer palette diversity from a
   filename, instruction count or three nonidentical channel gains alone.
3. Document the JSON contract and provide matched real-preset examples in
   Downloads, including limitations relevant to reconstruction/preference use.
4. Test source correctness, then freeze new predictions for human mood/appearance
   judgment. Existing judgments may diagnose gaps but cannot be holdout evidence
   after tuning. No rendered-frame classification feeds the source descriptor.

The finite RGB-envelope primitive remains experimental support work; do not
expand it into a general proof framework unless a descriptor/mood need warrants
that calculation. No full47-field replacement or new captured image is required
to finish this source-description milestone. Coverage, preference usefulness and
prediction accuracy are separate measurements.

## Approved quantitative extension sequence

The user approved all five extensions: timing/flash triggers, prominence,
movement, feedback and colour. Implement incrementally in this same worktree.

1. Add nominal RGB oscillator rates from scalar affine shader-time phases.
   Export signed radians/second, cycles/second, periods and unmasked component
   slope estimates. Preserve unknowns for audio/state/texture-dependent phases,
   integer casts and nonlinear time. Source31 wraps shader time every10000seconds;
   do not claim continuity across that reset or a measured visible flash rate.
   Add positive/negative formula tests before implementation, document the
   additive JSON contract and measure coverage on fixed cases.
2. Extend to discontinuous brightness/opacity triggers, including causal audio
   thresholds and affected channels. Trigger frequency needs declared audio
   history; no fixed frequency or Chill eligibility follows from a threshold.
3. Add projected primitive area, opacity and composition contribution estimates.
   Retain clipping, instance overlap, masks and authored-canvas conditions.
4. Add temporal/spatial derivatives for supported motion maps and named controls;
   distinguish feedback sampling displacement from visible object motion.
5. Add supported recurrence decay/amplification and transformed-copy analysis,
   preserving texture-content and nonlinear-feedback uncertainty.
6. Combine colour, area, motion and pulse facts into versioned mood/preference
   estimates. Freeze predictions before human assessment; calibrate mood mappings
   separately from source-math correctness. Keep unknowns in the denominator.

All steps require independently known formula controls, real-preset coverage,
contract documentation and review. The numerical47-field export stays unchanged.

## Quantitative checkpoint

- Nominal shader-time RGB timing is implemented; fixed100 has zero timing
  candidates, so no practical coverage gain is claimed for that rule.
- Direct-band switch sites are implemented;23/100presets have supported sites.
  Frequency/visible contrast remain unknown.
- Nominal custom-shape geometry is implemented;34/100presets have known area
  coefficients. Lifecycle, init/live inputs, compound writes and guarded division
  were corrected before those calculations; other state/reference effects remain
  explicit gaps. Clipping, union area and opacity contributions are still pending.
- Motion/transform rates, feedback recurrence and calibrated mood/preference
  matching remain required work. Existing47numeric fields stay unchanged.

See source-temporal, source-switch-sites and source-geometry evidence folders;
