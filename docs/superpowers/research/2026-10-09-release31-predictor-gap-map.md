# Published core 2.3.31 predictor migration gap map

Date: 2026-10-09. Read-only audit of predictor HEAD `ac914c0b2fb8374e7c2f899bcc1d707b627b5a94` against release commit `8a15996e8510533113a44e26feaddc3a7d6e85f5`. The latter contains 34 ordered engine patches; the prepared source29 identity models 16. This audit read release patches with `git show`, predictor source, and original MilkDrop2 2.25c source. It did not build adapters, render presets, operate devices, run a corpus, or change implementation files. The checks below are proposed migration discriminators, not executed results.

## Decision

Rebind the predictor to the published 2.3.31 source/AAR identity before adding static families. Admission alone is insufficient: patches 0017–0034 change several mathematical contracts copied into Python/C++, while two geometry changes are already inherited automatically by freshly built native waveform adapters. Preserve historical source29 behavior under its existing identity. Make new behavior explicit and include each selected policy in forecast provenance.

Already-correct behavior is limited: main-frame inverse aspect defaults, original border fans, existing CPU rotation/signed negative zoom policies, and existing per-wave Q/T timing should be retained. Per-pixel aspects are **not** already correct: their separate input assignment overwrites the inverse defaults with direct aspect factors.

Release patch links below are immutable at the release commit. Predictor references use `tools/milk-analyzer/<file>:line` and refer to the audited HEAD, before migration edits. Original references use the read-only root `/Users/jneerdael/Scripts/milkdrop2_v2.25c_OPEN_SOURCED_20130514_orig_code`; its `vis_milk2/milkdropfs.cpp`, `vis_milk2/plugin.cpp`, and `ns-eel2/nseel-compiler.c` were read directly.

## Order of migration checks

First qualify the fresh source31 parser/evaluator/wave/audio adapter identities and named constants. Then check custom input windows and equation provenance, legacy equation order/seam/path geometry, built-in opacity/RGB/count/closure, echo/gamma, shape styles, and continuous motion field/storage. Finish with composed synthetic numerical scenes that activate more than one of these contracts, including historical source29 controls. Keep unchanged border fans and original Q/T timing under regression checks.

No corpus-level fidelity, renderer output, physical-TV performance, backend shader compile parity, or native4K timing conclusion follows from this audit. New static families should consume the migrated source31 feature contract only after these targeted checks; old scored labels cannot become source31 labels by metadata relabeling.
