# Source polar projection parameters

The new per-sample `polar_projection` exports supported separable angular/depth
formulas with shared native or authored coordinate anchors, nominal angular
periods, reciprocal/logarithmic depth and radial derivatives. Constant-affine
planes may supply a basis/centre; dynamic/nonlinear planes retain a matching typed
program with unknown matrix/centre. Native aspect/projection/interpolation remains
conditional. These facts do not certify a dominant tunnel, exact visible symmetry,
layer count, final motion or recognizable reconstruction.

The target translator uses log(abs(...)); absolute inputs and domain guards are
retained. Source31 vendor/hlslparser/src/GLSLGenerator.cpp1028–1043 and
ShaderFields domain_checked lowering establish that policy. The original
MilkDrop2.25c D3DX source remains a separate authored reference, not an excuse to
change target behaviour. The creator's
[authoring guide](https://www.geisswerks.com/milkdrop/milkdrop_preset_authoring.html)
describes distorted/original coordinates and texture sampling/wrap effects.
Nominal angular cycles use actual authored constants, not rounded sectors.
