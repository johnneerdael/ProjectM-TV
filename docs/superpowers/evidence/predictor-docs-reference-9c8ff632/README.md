# Predictor documentation reference archive

These files are byte-for-byte documentation, schema and profile snapshots from
local source checkpoint `9c8ff6324c919188a1f6c4ddc48c5e19fc60cc82` (2026-10-10).
The manifest records each original path and SHA-256.

The checkpoint implementation is not published by this documentation-only PR.
This archive makes the cited contracts and evidence summaries available without
merging or publishing implementation commits. It contains no analyzer code,
compiled adapters, raw paired batches or complete reproduction environment.
Evidence statements retain their original checkpoint and qualification limits;
this integration does not rerun or extend that qualification.

Original paths are retained beneath this directory. The user guide links to
this archive at an immutable documentation commit, so later experimental branch
changes do not change the cited reference text.
