## U01 implementation and qualification

The model separates initialization shader canvas, authored frame canvas, native
render target and physical surface dimensions. It executes EEL and prepared
geometry once, replays the same state at both raster sizes, shares shader-random
inputs, preserves authored recurrence and blur ages, consumes the authored UV map
with target-sized motion geometry, and applies blockwise centered detail gain.
Standard skips the native warp; Medium/High use .5/1. Same-size gain-class changes
rebuild authored feedback but retain valid UV and blur history. Native composite
precedes any physical surface blit.

This resolves the original U01 high-resolution/reference-context limitation for
**explicitly allocated, pinned v2.3.27 Apple GLES authored/native contexts**. The
full unchanged published AAR, Java classes, native bytes, clock and input data are
bound by [qualification-checkpoint.json](runtime2327/qualification-checkpoint.json).
Unknown allocation, noninteger canvases and unqualified ordinary/diffusion paths
retain guards. Exact preset/hash/phase contracts remain required.

Four frozen 30-frame full-AAR controls pass: canvas dimensions (max RGB8 error0),
Medium detail (1), High detail (1), and zoomed feedback/moving custom shape (1).
The feedback control contains30 distinct fields and tests one shared-register
update per frame. Its actual decay is1 because the first duplicate key wins;
no .97 fading claim is made. Every source/native frame record was independently
decoded, hashed and numerically compared. The Standard gathering error was
recovered without repeating native frames and is explicitly retained in evidence.

The [physical blit proof](runtime2327/physical-blit/README.md) has six exact full
RGBA8 comparisons at1920×1080→3840×2160. It qualifies the isolated GL_LINEAR
operator with this backend; it is not a whole core transition. Blur, motion and
gain-switch evidence remains analytical rather than claimed full-AAR coverage.
No AI/human image inspection supplied these predictions.
