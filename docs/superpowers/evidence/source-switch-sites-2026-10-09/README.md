# Source-only band switch sites

The approved quantitative appearance work now exports `audio_routes[].switch_triggers`.
`source_triggers.py` recognizes contributing direct-band greater/less comparisons,
including reversed operands. It retains typed threshold values or threshold DAGs,
per-element/control/input identity, a graph-path string, and source true/false
levels only for complete scalar comparison/conditional controls with known branches.
Nested sites keep whole-control jumps unknown. Native float coercion of integer
branches is honored; strict band self comparisons and equal complete branches do
not produce switching evidence. `int(audio)` is not treated as a direct band.

This does not execute audio, equations, shaders or display frames. Trigger
frequency, screen area, visible contrast and mood confidence remain unknown.
These are source predicate sites, not certified visible discontinuities or flashes.
Empty results do not prove absence. Comparison sites under loops/control gates
retain reachability/termination/composition conditions. No numerical47-field metric
is replaced. The full published2.3.32AAR is still the latest release checked here;
its byte-equivalent source31 adapters and engine policies remain unchanged.
