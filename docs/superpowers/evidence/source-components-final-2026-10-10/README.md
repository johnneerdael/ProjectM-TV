## Final integration checks

The prepared suite, including all optional backends, passed 3,266 tests plus
92 subtests in 200.68 seconds. The unchanged fixed 100 complete source exports
all computed, passed the appearance-description JSON schema and retained matching
model hashes. All 100 include the optional dependency supplement; none uses a
rendered reference. The source-bound compile manifest and declared scenario
remain separate from native runtime verification.

Independent review found and repaired: bundle/config byte attribution,
post-supplement publication identity checks, false Slang derivative acceptance
from comments/dead calls, and incorrect physical source text for #line directives.
Mutation/negative controls are retained.

Combined testing then exposed a standalone Stims cache-ownership defect: Flexi's
shared expression graph expanded repeatedly after the ordinary analyzer scope
ended. The public API now owns a scoped cache when needed, reuses caller scopes
and restores ownership on exceptions. The exact preset with all original flags
was retested in 0.672 seconds before the repaired 100 export and full suite ran.
The interrupted run is preserved under build; it is not credited as successful.
The earlier full-pack Stims census had supplied this cache and remains distinct
valid scoped evidence. No shared core graph policy changed.
