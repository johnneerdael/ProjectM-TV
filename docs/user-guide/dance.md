# Former Dance collection

Dance has been replaced by **Chill**, **Normal** and **Intense** in the predictive preset engine beta. **All** remains the default. A previously saved Dance selection returns to All.

Choose **Preset mood** in the settings panel. See [Predictive collections](predictive-collections.md) for the score ranges and limits.

The [historical Dance measurement article](dance-measurement.md) preserves the earlier bass-response research; its 500-member collection is no longer shipped.
