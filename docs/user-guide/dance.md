# Dance collection

**Dance contains 500 presets selected automatically for large bass-caused changes on screen.** It is a prebuilt collection of existing MilkDrop presets, with their original equations and shaders.

## Select it

1. Press **Center, Enter or Menu** to open the settings panel.
2. Move to **Music category**.
3. Use **Left / Right** or **Center** to choose **Dance**.

Your choice is saved. Automatic changes, Random and Previous stay within Dance. **All** remains the default and makes the full library available.

## What was selected

The offline analyzer renders each candidate with a matched steady audio control and three controlled bass levels. It ranks the visible changes across the entire screen, so a tiny bouncing element receives less credit than a large scene transformation.

Strength varies across the 500. Some presets react through color or brightness, others through geometry and feedback. The measurement describes the specified test inputs and renderer; the response can differ with your music, resolution and GPU.

Your TV's existing skip rules still apply. If one member is already skipped locally, the eligible count is 499 even though the collection packages 500 presets. An unavailable category falls back to All.

## Technical detail

[How Dance is measured](dance-measurement.md) explains the full experiment, formulas, ranking, source identities and limitations. The initial scan attempted all 9,606 presets; the release's 500 were selected from candidates revalidated with the current production renderer.

A calm **Chill** collection is future work. Low bass response alone does not establish smooth, non-flashing motion, so it needs separate movement measurements.
