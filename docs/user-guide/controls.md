# Remote controls

| Key | While visuals are showing |
|---|---|
| Right, Next, Fast forward | Random preset, instant cut |
| Left, Previous, Rewind | Previous preset, instant cut |
| Up, Down, Info | Show the current track again, with notification access |
| Center, Enter, Menu | Open the settings panel |
| Back | Exit the app |

## In the settings panel

- **Up / Down:** move between rows.
- **Left / Right:** change a value.
- **Center:** cycle a value or run an action.
- **Back:** close the panel; from Advanced, return to the main panel.
- **Menu:** close the panel.

The panel hides after ten seconds without input.

![ProjectM TV settings panel](images/setup/main-settings.png)

The current preset name and audio level appear in the main panel. Use **Music category** to switch between All and Dance. Navigation stays within the selected collection, subject to device-specific skips. Changing category clears the old navigation history and applies the new selection with a hard cut.

The available settings are listed in the [settings reference](settings.md).
